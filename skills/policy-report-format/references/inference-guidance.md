# Inference Guidance

Pre-reads: [attributes.md](attributes.md),
[statement-patterns.md](statement-patterns.md).

The user should never be asked for something their input already supports.
Input arrives in any shape — an idea, an email thread, a draft, meeting
notes — and it need not use this skill's vocabulary. Read the WHOLE
content and derive each attribute from whatever is there.

## What counts as a basis

- **Directly stated** — the fact is written, in any phrasing. "Everyone
  working from home must use the VPN" is a basis for a PA18 statement, for
  PA8 scope (remote workers), and a hint for PA3 (Security or Operational).
- **Composable** — the pattern's ingredients are present even though the
  finished sentence is not (see statement-patterns.md). Having the subject,
  audience, and outcome anywhere in the content IS a basis for PA7 —
  compose it and present it for confirmation.
- **Strongly implied** — a fact a careful reader would accept without new
  information: a policy written to satisfy "the new data protection law"
  implies PA3 = Compliance and gives PA13 its first entry; mention of an
  annual audit implies a basis for PA25/PA28.
- **Combinable across passages** — facts scattered across distant sections
  combine: an incident anecdote (PA11 context, PA14 risk) plus a named
  team (PA23) plus a deadline (PA10).

## What does NOT count

- A topic mention with no content ("we should say something about
  training" does not populate PA31).
- Your own domain knowledge of what similar policies usually contain.
  Fill from the content, or mark the attribute missing.
- Placeholders in the source ("TBD by legal") — carry the gap, not the
  placeholder.

## Attitude

Mark an attribute missing ONLY when the content carries no basis
whatsoever. Everything marked missing becomes a question the user must
answer, so inference left on the table costs them work. A defensible
inferred value the user can correct in one word beats a question they must
answer from scratch. Longer input means MORE populated attributes, not
more questions.
